# 🌿 Umas Community · Rules Web 3.0

Reglamento oficial y manual interactivo de convivencia, seguridad digital, matriz sancional determinista, test de onboarding, soporte multilingüe y panel de moderación para **Umas Community**.

🌐 **Sitio en Producción:** [https://rules-web.onrender.com](https://rules-web.onrender.com)

---

## 🌟 Características de la Versión 3.0

1. **Buscador Contextual Command Palette:** Búsqueda ponderada con sinónimos (`acoso` ↔ `hostigamiento`, `doxxing` ↔ `privacidad`), atajos `/` o `Ctrl+K`, lista interactiva y auto-scroll con resplandor esmeralda.
2. **Panel de Moderación Oficial (Staff):** Conectado al backend seguro de Express para registrar reportes disciplinarios y enviarlos a canales privados de Discord vía Webhooks.
3. **Test de Convivencia & Onboarding:** Experiencia formativa con 5 casos prácticos situacionales y constancia digital descargable.
4. **Soporte Multilingüe (i18n):** Disponible en Español (`ES`), Inglés (`EN`) y Portugués (`PT`).
5. **PWA Offline con Service Worker:** Instalable en dispositivos móviles y ejecutable sin conexión a internet.
6. **Simulador Sancional Determinista:** Escala de 0 a 100 PTS con 3 factores y exportación de informe para Discord.
7. **Estilos de Impresión (@media print):** Diagramación para exportar el reglamento completo a PDF.
